# SponsorFit 🏆

**SponsorFit** is a data-driven sports sponsorship analysis project that helps compare sports based on **audience reach, brand fit, engagement, cost efficiency, growth, and risk**.

The project evaluates six sports:

* Cricket
* Kabaddi
* Football
* Badminton
* Hockey
* Distance Running

## 📊 Features

* Sports sponsorship data analysis
* Multi-criteria scoring
* AHP, TOPSIS and Entropy methods
* Sensitivity analysis
* Monte Carlo simulation
* Interactive dashboard
* Data visualization

## 🛠️ Tech Stack

* **Python**
* **HTML / CSS / JavaScript**
* **CSV**
* **AHP**
* **TOPSIS**
* **Entropy Weighting**
* **Monte Carlo Simulation**

## 📈 Analysis

SponsorFit compares sports using seven criteria:

* Audience Reach
* Audience–Brand Fit
* Fan Engagement
* Image Congruence
* Cost Efficiency
* Growth Trend
* Risk Safety

The project uses sourced indicators along with expert-rated criteria to generate sports scores. The dataset contains **19 sourced indicators**.

## 🎯 Purpose

The goal is to demonstrate how **sports analytics and decision-making techniques** can be used to support sponsorship decisions through data, scoring models, and interactive visualization.
